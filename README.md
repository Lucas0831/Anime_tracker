# 追番助手（Anime Tracker Assistant）

按星期展示正在播出的番剧：放送日期、北京时间、更新集数、作品信息。面向追番数量较多、信息分散在多个网站与 App 中的动漫爱好者。

本仓库当前阶段为 **纯前端静态可点击原型**：不接任何真实接口、不依赖构建工具、全部数据为本地假数据。

## 当前状态

| 项目 | 说明 |
| --- | --- |
| 版本 | v0.1.0（可点击原型） |
| 定位 | 微信小程序（正式产品），当前以 Web 原型验证信息架构与交互 |
| 数据 | 21 部假番剧，覆盖 7 天，全部写死在 `prototype/data.js` |
| 最短通关路径 | ① 打开小程序，查看首页当天的番剧时间线 → ② 关闭小程序 |
| 正式技术栈（规划） | uni-app + Vue + 云开发（云数据库），不使用第三方 SDK |

## 快速开始

方式一：直接双击打开 `prototype/index.html`（`file://` 协议即可运行）。

方式二：启动本地静态服务（推荐，避免个别浏览器对本地文件的限制）：

```powershell
cd prototype
python -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765/
```

建议以 `390 × 844`（iPhone 尺寸）视口查看，桌面端会以 420 × 860 的手机框展示。

## 页面与路由

原型共 5 个页面，通过 hash 路由串联：

| 页面 | 路由 | 说明 |
| --- | --- | --- |
| 时间线页 | `#/timeline` | 落地页，默认聚焦今天，按时间轴展示当天番剧 |
| 列表页 | `#/list` | 同一天的列表浏览方式 |
| 网格页 | `#/grid` | 同一天的网格浏览方式，海报封面优先 |
| 详情页 | `#/detail/<id>` | 番剧详情、评分、下一集、平台与标签 |
| 搜索页 | `#/search` | 按标题 / 日文名 / 标签搜索，含热门关键词 |

左上角视图按钮在时间线 → 列表 → 网格之间循环切换；右上角进入搜索；任意卡片进入详情，详情返回时回到来源页。

## 功能范围

已实现（原型）：

- 时间线 / 列表 / 网格三种浏览方式与循环切换
- 周日期切换（10-26 ~ 11-01，默认今天），全部 / 番剧 / 国创 / 已追筛选
- 番剧详情（4 家评分、下一集倒计时、信息 / 工作室 / 标签 / 平台 / 外部链接）
- 搜索（标题、日文名、标签匹配；热门关键词；关键词保留与清空）
- 追番收藏、分享占位、标签展开、回到顶部、各种空状态

非目标（见 PRD 边界）：

- 不做个人追番管理、提醒与外部联动、视频与社区功能
- 原型不发起任何网络请求，不写入真实用户数据
