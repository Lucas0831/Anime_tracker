# 全局 UI 设计规范（DESIGN）

本文件只定义跨页面的全局 UI 规范：设计原则、视觉语言、色彩与材质、字体、图标、尺寸、动效、响应式与可访问性。

- 页面结构、路由、逐页模块与交互状态：见 [页面与交互规格](./PAGE_SPEC.md)
- 数据模型、小程序实现与已知限制：见 [实现说明](./IMPLEMENTATION.md)
- 产品目标、最短路径与边界：见 [初版PRD](../初版PRD.md)

适用对象为 `prototype/` 静态原型与 `miniapp/` 小程序，两者共用同一套视觉语言；页面比例与文案由 PAGE_SPEC 约束。

## 1. 设计原则

- **一眼看到今天看什么**：首屏信息密度服务于“今天”，按放送时间从早到晚排列。
- **三种浏览方式各有侧重**：时间线看“几点更新”，列表看“标题与集数”，网格看“海报与封面”。
- **详情只补充决策所需信息**：下一集、作品信息，不放视频、社区、追番管理与外部链接。
- **路径最短**：打开 → 看懂今天时间线 → 关闭，不强迫登录、关注或设置。

## 2. 视觉语言

- **克制、编辑式**：大量留白、发丝线分隔、少用独立卡片堆叠；层级靠亮度、间距与字重建立，而不是重阴影或强对比。
- **液态玻璃**：页面分为「页面底 / 玻璃面 / 悬浮面」三层，每层只差一点亮度；玻璃边缘加 1rpx 内侧高光模拟厚度。
- **材质边界**：玻璃只用于导航、可点击容器与浮层；正文与长文本保持不透明，优先保证可读性。
- **单色为主**：整体近黑白灰，蓝色 `--accent` 仅用于选中与强调；数字使用专属字体作为节奏点。
- **可离线**：不使用外链图片、外链字体或第三方视觉资源。

## 3. 色彩与材质

### 3.1 基础色

| 项 | 原型（`prototype/styles.css`） | 小程序（`miniapp/src/styles/app.css`） |
| --- | --- | --- |
| 主文本 | `--ink: #111114` | `--ink: #131316` |
| 次级文本 | `--ink-2: #34343a` | `--ink-2: #3a3a41` |
| 辅助文本 | `--muted: #8e8e94` | `--muted: #62626a`、`--muted-2: #6f6f77` |
| 分割线 | `--line: #ececee` | `--line: rgba(20,20,30,0.08)`、`--glass-line: rgba(18,18,28,0.06)` |
| 浅底 / 凹槽 | `--soft: #f4f4f5`、`--soft-2: #f7f7f8` | `--soft: rgba(20,20,30,0.05)`、`--soft-2: rgba(20,20,30,0.032)` |
| 卡片面 | `--card: #ffffff` | `--card: #ffffff` |
| 强调色 | `--accent: #0a84ff` | `--accent: #0a84ff` |
| 页面背景 | 常规页纯白；搜索页为浅灰渐变 + 冷 / 暖径向光斑 | `--bg-top: #f8f9fb` → `--bg: #eef0f4` 纵向渐变 + 顶部极淡光斑 |

强调色只用于底部 Tab Bar 选中项的图标与文案；其余可点击态靠凹槽底色与文字深浅表达。

### 3.2 液态玻璃

| 项 | 值 |
| --- | --- |
| 玻璃面 | `--surface-1: rgba(255,255,255,0.56)` → `--surface-2: 0.72` → `--surface-3: 0.88`，按压时升一级 |
| 玻璃边缘 | `--glass-edge: rgba(255,255,255,0.72)`；玻璃面之间的分隔用 `--glass-line: rgba(18,18,28,0.06)` |
| 凹槽 | `--soft` / `--soft-2`，用于搜索框、筛选器、内嵌 chip |
| 阴影 | `--shadow-1 / --shadow-2 / --shadow-3` 三级外阴影 + `--sheen` 内侧 1rpx 高光 |
| 模糊半径 | 顶栏 34rpx、底部 Tab Bar 30rpx、详情「下一集」卡 26rpx、圆形悬浮按钮 28rpx |
| 回退 | 端上不支持 `backdrop-filter` 时回退为半透明不模糊底色 |
| 适用范围 | 顶栏、底部胶囊 Tab Bar、时间线 / 列表 / 搜索结果面板、详情「下一集」卡、搜索框、最近搜索与标签探索面板、圆形悬浮按钮 |

## 4. 字体与排版

| 项 | 值 |
| --- | --- |
| 正文字体 | `-apple-system, "SF Pro Text", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei"` |
| 数字字体 | `"NeutraText-DemiAlt", "NeutraText", "Neutra Text Light Alt", "Century Gothic", "Avenir Next", "Futura", "Trebuchet MS"` |
| 字号阶梯 | 原型按 390 设计宽使用 23 / 19 / 18 / 16 / 15 / 14.5 / 14 / 13.5 / 13 / 12.5 / 12 / 11.5 / 11 / 10.5 / 10 / 9.5px；新增样式优先复用既有阶梯 |
| 字重 | 页面标题 400（不加粗）；卡片标题与区块标题 600~700 |
| 字距 | 小号全大写式标签（如「搜索结果」）使用 `0.08em`，其余接近 0 |

- 字体在原型中通过 `assets/NeutraText-DemiAlt.otf` 加载；小程序以 base64 `@font-face` 内嵌，保证 H5 与小程序一致。
- 小程序字号按 390 → 750 设计宽换算为 `rpx`，比例与原型一致。

## 5. 图标

- 内联 SVG，`24 × 24` viewBox，统一线宽 1.5，圆角线帽，仅用描边不用填充。
- 默认颜色 `#8e8e94`；深色底上使用白色。
- 原型：`ICONS` 映射 + `icon(name)` 渲染；新增图标同时补充 `ICONS` 与必要的 `ICON_ALIASES`。
- 小程序：`src/icons.js` 维护 SVG 路径，以 `data:image/svg+xml` 作为 `.app-ico` 背景图渲染。
- 图标尺寸随容器在 14~24px 之间取值，不单独放大。

## 6. 圆角、尺寸与间距

| 项 | 值 |
| --- | --- |
| 圆角 | 卡片 12~18px（小程序按 rpx 等比），胶囊 999px，手机壳 34px |
| 海报尺寸 | 时间线 80×108、列表 78×100、网格封面 378:442、详情 118×164 |
| 页面边距 | 左右固定 20px（小程序 38.46rpx） |
| 组件间距 | 8px（15.38rpx）为基准，区块之间 20px（38.46rpx） |
| 布局 | 移动优先；桌面手机壳 420 × 860，视口 ≤ 520px 时全屏 |
| 安全区 | 底部内容使用 `env(safe-area-inset-bottom)`；悬浮 Tab Bar 本身不叠加安全区 |

## 7. 动效

- 轻量过渡为主：颜色 / 背景 150~280ms；页面切换沿方向轻推 14px 并淡入。
- 选中类交互使用弹簧：约 420ms 停稳，前沿先到、后沿稍慢并轻微回弹；具体参数与 Tab Bar 时序见 [PAGE_SPEC](./PAGE_SPEC.md#36-底部悬浮胶囊-tab-bar)。
- 动效只服务于状态变化，不做装饰性循环动画。
- 遵循 `prefers-reduced-motion`：开启「减少动态效果」时直接跳到终态。

## 8. 响应式

- 视口 ≤ 520px：手机壳铺满屏幕，隐藏桌面提示。
- 视口 > 520px：居中手机框 + 底部操作提示。
- 原型与小程序均以 390 × 844 为基准比例；小程序按 750 设计宽编写 `rpx`。
- 所有界面必须在 390 × 844 与 ≤ 520px 全屏两种形态下可用，不出现横向裁切。

## 9. 可访问性

- 所有图标按钮带 `aria-label`；卡片使用 `role="button"` + `tabindex="0"`。
- 焦点态 `:focus-visible` 使用 2px 黑色描边；可点击区域不小于 44 × 44px。
- 图片懒加载（`loading="lazy"`），海报带 `alt`。
- 辅助文字与来源徽章需满足对比度：小程序辅助色已加深为 `#62626a` / `#6f6f77`，徽章保持浅色底但文字加深。

## 10. 资源规范

- 海报文件名必须等于番剧 `id`：原型 `assets/<id>.jpg`，小程序 `static/<id>.jpg`。
- 不引用外链图片；字体使用本地文件或 base64 内嵌。
- 不提交未使用的图片与字体资源。
