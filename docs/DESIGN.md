# 设计说明（DESIGN）

本文件描述追番助手静态原型的信息架构、页面规格、交互状态、视觉规范与数据模型。设计依据为 [初版PRD](../初版PRD.md) 与四张原型图。

## 1. 设计目标

- **一眼看到今天看什么**：落地页默认聚焦今天，按放送时间从早到晚排列。
- **三种浏览方式各有侧重**：时间线看"几点更新"，列表看"标题与集数"，网格看"海报与封面"。
- **详情只补充决策所需信息**：下一集、作品信息，不放视频、社区、追番管理与外部链接。
- **路径最短**：打开 → 看懂今天时间线 → 关闭，不强迫登录、关注或设置。

## 2. 信息架构

```text
时间线页 #/timeline（落地页，默认今天）
├── 切换视图 → 列表页 #/list
│                └── 切换视图 → 网格页 #/grid
│                                  └── 切换视图 → 时间线页
├── 搜索入口 → 搜索页 #/search
│                └── 结果卡片 → 详情页 #/detail/<id>
└── 番剧卡片   → 详情页 #/detail/<id>
                  └── 返回 → 来源页（时间线 / 列表 / 网格 / 搜索）
```

页面总数：**5 个**（时间线、列表、网格、详情、搜索）。

## 3. 路由表

| 页面 | hash 路由 | 进入方式 | 返回目标 |
| --- | --- | --- | --- |
| 时间线 | `#/timeline` | 默认、视图切换、返回 | — |
| 列表 | `#/list` | 时间线左上角切换 | 时间线 |
| 网格 | `#/grid` | 列表左上角切换 | 列表 |
| 详情 | `#/detail/<id>` | 任意番剧卡片、搜索结果 | 记录在 `state.returnTo` 的来源页 |
| 搜索 | `#/search` | 时间线 / 列表 / 网格右上角 | 记录在 `state.returnTo` 的来源页 |

- 未知路由回退到 `#/timeline`；未知详情 id 回退到默认番剧 `tenchi`。
- 返回详情时保留搜索关键词；从时间线切到其他视图时重置筛选为「全部」。

## 4. 页面规格

### 4.1 时间线页（`#/timeline`）

| 区域 | 内容与规则 |
| --- | --- |
| 顶栏 | 左：视图切换（时间线 → 列表）；中：标题「番剧时间轴」（随当前页切换，不加粗）；右侧留空以保持标题居中，搜索入口统一放在底部 Tab Bar |
| 周日期条 | 7 个日期格（10-26 ~ 11-01），显示月-日 + 星期；圆点跟随当前选中日期；固定在顶栏下方，不随滚动移动 |
| 日期栏 | 当前日期 + 星期；跟随周日期条固定；筛选与搜索入口移至底部悬浮胶囊 Tab Bar |
| 时间线主体 | 左侧时间轴竖线 + 时间标签 + 海报 + 标题/日文名/标签/集数；按时间升序分组；时间节点吸顶在日期栏下方 |
| 空状态 | 两种文案：当日无番剧、筛选无结果（带「查看全部」） |

单条卡片交互：点击卡片 → 详情。整页左右滑动可在相邻日期间切换（左滑到下一天、右滑到上一天）。

### 4.2 列表页（`#/list`）

- 顶栏与时间线一致，标题为「番剧列表」，左上角图标语义变为「切换到网格视图」；顶栏（标题 + 日期胶囊）整体固定，不随滚动移动。
- 用横向日期胶囊代替时间线条，节省纵向空间；7 个胶囊等宽平铺整行。
- 卡片：海报 + 标题 + 日文名 + 元信息胶囊（`时间 + 已播/待播`、`# 第N集`、国漫标识）。
- 底部留白，点击整卡进入详情。

### 4.3 网格页（`#/grid`）

- 三列海报网格，封面左下角叠加半透明时间标签「HH:MM 播放」；顶栏（标题 + 日期胶囊）整体固定，不随滚动移动。
- 标题两行截断；点击进入详情。
- 左上角图标语义为「切换到时间线视图」，标题为「番剧网格」。

### 4.4 详情页（`#/detail/<id>`）

| 区块 | 内容 |
| --- | --- |
| 头图 | 海报模糊背景 + 返回；海报、标题、集数、放送状态 |
| 下一集卡 | 第 N 集 / 共 M 集、放送日期（北京时间）、距开播倒计时 |
| 简介 | 简介文本，默认最多 4 行 |
| 信息 | 来源徽章（漫画改编 / 轻小说改编 / 原创动画；漫画改编为浅紫、原创动画为浅粉）+ 集数、季度、放送状态、制作、类型、放送时段 |
| 工作室 | 制作公司胶囊 |
| 标签 | 默认展示 6 个，可「更多 / 收起」 |
| 回到顶部 | 右下角悬浮按钮 |

详情页底部页面级留白，避免最后一行贴安全区，并为右下角「回到顶部」按钮预留空间，避免遮挡标签「更多」按钮。

### 4.5 搜索页（`#/search`）

- 顶栏：返回 + 搜索框（含清空按钮）+ 自动聚焦能力。
- 空关键词：只展示「搜索历史」标签（初始 4 条，最多保留 8 条，最近搜索置顶），右上角可「清空」；无记录时显示「暂无搜索记录」。
- 有结果：显示「找到 N 部番剧」+ 结果行（海报、标题、日文名、星期时间、番剧/国漫、第 N 话）。
- 匹配范围：标题、日文名、制作公司、季度、分类（番剧/国创/国漫）、tags、extraTags、genres。
- 无结果：搜索空状态，提示更换关键词。

### 4.6 底部悬浮胶囊 Tab Bar

时间线、列表、网格三页共用一条悬浮在页面底部的胶囊 Tab Bar，分左右两部分：

| 部分 | 内容 | 规则 |
| --- | --- | --- |
| 左侧筛选组 | 全部 / 番剧 / 国漫 | 每项为「图标 + 文案」纵向排列（层叠 / 放送 / 地球），三枚等分嵌在一个玻璃胶囊内；选中背景撑满对应 Tab，图标与文案转为强调色 `#0a84ff`；切换后保持滚动位置，视图切换时筛选不变 |
| 右侧搜索胶囊 | 搜索图标 | 独立圆形玻璃胶囊，与主胶囊等高，点击进入搜索页 |

- 布局：屏幕左右固定边距 20px（小程序 38.46rpx），主胶囊 `flex: 1` 占满剩余宽度，搜索胶囊固定 56px × 56px（小程序 107.69rpx），两者间距 8px（15.38rpx）；整组约占屏宽 90%，宽度由容器分配而非内容撑开。
- 外形：主胶囊高 56px（小程序 107.69rpx），圆角取高度一半 28px（53.85rpx），呈完整胶囊形态；内层 Tab 圆角 23px（44.23rpx），主胶囊内边距 5px（9.62rpx）。
- 距底部 20px（小程序 38.46rpx），与左右固定边距一致；小程序不再叠加 `env(safe-area-inset-bottom)`，避免安全区把底部间距撑成左右边距的两倍以上（底部内容留白仍保留安全区）。
- 容器本体不接收事件，仅胶囊本身可点击，避免遮挡底部卡片的滚动与点击。
- 三页底部留白相应加大（原型 82px、小程序 157.69rpx，含安全区），避免最后一行内容被 Tab Bar 覆盖。
- 切换动效：选中胶囊由独立指示层承载，前沿与后沿分别用不同刚度的弹簧追赶目标，前沿先到、后沿稍慢并轻微回弹，中途胶囊被拉长且高度略压扁，约 420ms 停稳；新选中的图标先缩小再弹回，文字颜色在约 280ms 内渐变到强调色；页面内容沿点击方向轻推 14px 并淡入。最终选中态与静态样式完全一致，开启「减少动态效果」时直接跳到终态。

## 5. 交互与状态

| 状态 | 触发 | 表现 |
| --- | --- | --- |
| 视图循环 | 左上角按钮 | 时间线 → 列表 → 网格 → 时间线 |
| 日期切换 | 周日期条 / 日期胶囊 | 重渲染并回到顶部；时间线只显示选中日 |
| 横向滑动切换日期 | 在时间线 / 列表 / 网格页横向滑动 | 左滑切到下一天、右滑切到上一天；首尾日期不循环；纵向为主的滑动不触发 |
| 时间线滚动 | 纵向滚动时间线 / 列表 / 网格 | 顶栏区块（标题 + 周日期条 / 日期胶囊，时间线另含日期栏）在三个视图中均固定不滚动；当前分组的时间节点始终吸顶在日期栏下方；滚动到下一时间点时，新节点从下方将旧节点顶出 |
| 筛选 | 底部 Tab Bar 的全部 / 番剧 / 国漫 | 保持滚动位置筛选；选中胶囊以液态弹簧动效流向新 Tab（前沿先到、后沿回弹、中途拉伸压扁，约 420ms），图标先缩后弹、文字渐变强调色，内容沿点击方向轻推淡入；无结果时引导去查看全部；在时间线 / 列表 / 网格间切换视图时筛选保持不变 |
| 打开搜索 | 底部 Tab Bar 的搜索胶囊 | 进入搜索页；返回时回到来源视图 |
| 键盘 | Enter / Space | 聚焦卡片时打开详情 |
| 回到顶部 | 详情右下角 | `scrollTop = 0` |
| 刷新 | 浏览器刷新 | 内存态（筛选、关键词、搜索历史）重置为初始值 |

### 6.1 小程序 · 液态玻璃与微对比色阶

小程序页面不再使用纯白底，而是把内容分成「页面底 / 玻璃面 / 悬浮面」三层，每层只差一点亮度，并在玻璃边缘加 1rpx 内侧高光模拟厚度。玻璃只用于导航与可点击容器，正文保持不透明以守住可读性。

| 项 | 值 |
| --- | --- |
| 页面底 | `--bg-top: #f8f9fb` 到 `--bg: #eef0f4` 的纵向渐变，顶部叠加两团极淡的冷 / 暖径向光斑 |
| 玻璃面 | `--surface-1: rgba(255,255,255,0.56)` → `--surface-2: 0.72` → `--surface-3: 0.88`，按压时升一级 |
| 玻璃边缘 | `--glass-edge: rgba(255,255,255,0.72)`；玻璃面之间的分隔用 `--glass-line: rgba(18,18,28,0.06)` |
| 凹槽 | `--soft: rgba(20,20,30,0.05)`、`--soft-2: rgba(20,20,30,0.032)`，用于搜索框、筛选器、内嵌 chip |
| 阴影 | `--shadow-1 / --shadow-2 / --shadow-3` 三级外阴影 + `--sheen` 内侧 1rpx 高光 |
| 强调色 | `--accent: #0a84ff`，仅用于底部 Tab Bar 选中项的图标与文案 |
| 材质范围 | 顶栏、底部胶囊 Tab Bar、时间线 / 列表 / 搜索结果卡片、详情「下一集」卡、搜索框、历史标签、圆形悬浮按钮 |
| 模糊半径 | 顶栏 34rpx、底部 Tab Bar 30rpx、详情「下一集」卡 26rpx、圆形悬浮按钮 28rpx；端上不支持 `backdrop-filter` 时回退为半透明不模糊底色 |
| 文本 | `--ink: #131316`、`--ink-2: #3a3a41`、`--muted: #62626a`、`--muted-2: #6f6f77`；来源徽章保持浅色底但文字加深以满足对比度 |

## 7. 数据模型

数据默认来自本地文件，云数据库可用时整体替换为云端数据（失败自动回退本地）：

- 原型：`prototype/data.js`，挂载在 `window` 上；
- 小程序：`miniapp/src/data/anime.js`（本地兜底），`miniapp/src/cloud/`（云查询与字段映射）。
- 云数据库：`anime`（番剧主表）、`airing_schedule`（分集放送时间表）、`sync_state`（同步状态）、`match_review`（中文名审核）。
- 集合字段、接口来源与映射明细见 [字段与接口来源文档](./字段接口来源文档.md)。

```text
window.WEEK:        [{ label, md, date }] × 7   // 周日期
window.TODAY_INDEX: number                      // 今天在 WEEK 中的下标（0）
window.ANIME:       AnimeItem[]                 // 21 部
window.SEARCH_HISTORY: string[]                 // 搜索历史初始数据
```

`AnimeItem`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 唯一标识，同时对应海报文件名 |
| `day` | number | 星期下标 0~6 |
| `time` | string | 北京时间 `HH:MM` |
| `ep` / `totalEps` | number | 当前集 / 总集数 |
| `category` | `'anime' \| 'guochuang'` | 番剧 / 国创 |
| `title` / `jp` | string | 中文名 / 日文名（国创可为空） |
| `poster` | string | 原型 `assets/<id>.jpg`；小程序 `/static/<id>.jpg` |
| `tags` / `extraTags` | string[] | 主标签 / 扩展标签（详情「更多」） |
| `studio` / `season` / `status` | string | 制作 / 季度 / 放送状态 |
| `genres` | string[] | 类型（英文分类） |
| `ratings` | number[4] | MAL / Bangumi / AS / TMDB |
| `next` | object | `{ ep, total, date, countdown }` 下一集信息 |
| `synopsis` | string | 简介 |
| `platforms` | string[] | 播出平台（原型不展示，边界线内功能） |

假数据分布：共 21 部，周一 9 部、周二至周日各 2 部；番剧与国创混合。海报共 21 张，其中 10 张裁切自原型图、11 张为本地生成的风格化封面。

## 8. 响应式与可访问性

- 视口 ≤ 520px：手机壳铺满屏幕，隐藏桌面提示。
- 视口 > 520px：居中手机框 + 底部操作提示。
- 所有图标按钮带 `aria-label`；卡片使用 `role="button"` + `tabindex="0"`。
- 焦点态 `:focus-visible` 使用 2px 黑色描边。
- 图片懒加载（`loading="lazy"`），海报带 `alt`。

## 9. 小程序实现（`miniapp/`）

技术栈：uni-app + Vue 3 + Vite，目标平台微信小程序（`mp-weixin`），H5 仅用于本地预览。

| 原型页面 | 小程序路由 | 说明 |
| --- | --- | --- |
| 时间线 / 列表 / 网格 | `pages/index/index` | 单页内通过 `view` 状态切换三种浏览方式，共享日期与筛选 |
| 搜索 | `pages/search/search` | 独立页面，返回时保留关键词 |
| 详情 | `pages/detail/detail?id=<id>` | 独立页面，返回来源页 |

- 样式按 390 设计宽等比换算为 `rpx`（750 设计宽），移动端比例与原型一致。
- 图标由内联 SVG 路径生成 `data:image/svg+xml`，作为 `.app-ico` 背景图渲染，统一 1.5 线宽。
- 状态存放在 `src/store.js` 的 `reactive` 单例中，仅内存保存；搜索历史、当前视图与日期在页面间共享。
- 云开发：`App.vue` 启动时 `initCloud()` 初始化 `wx.cloud`，`loadAnime()` 拉取 `anime` 集合；`src/cloud/index.js` 优先调用云函数 `animeApi`（`list` / `detail` / `week`），失败后直查数据库，仍失败则保留本地假数据。
- 云函数源码位于 `miniapp/cloudfunctions/`，构建时同步到小程序产物 `cloudfunctions/`，由微信开发者工具上传部署：
  - `animeApi`：小程序端读查询（`list` / `detail` / `week`）；
  - `animeSync`：服务端同步 AniList / Bangumi / AnimeSchedule 数据到云数据库。
- 云环境 ID 通过 `.env.local` 的 `VITE_CLOUD_ENV` 注入，不写入仓库；未配置时使用默认云环境。
- 数字字体 NeutraText-DemiAlt 以 base64 `@font-face` 内嵌在 `src/styles/app.css`，确保 H5 与小程序端一致；原型使用 `assets/` 下的本地字体文件。

## 10. 已知限制（原型阶段）

- 数据为静态假数据与云数据库双通道：云查询失败或 H5 预览时回退本地数据，刷新即重置，无持久化、无登录。
- PRD 边界内的个人追番管理、外部联动、视频与社区不实现。
- 云函数需在微信开发者工具手动上传部署；仓库不提交 AppID 与云环境 ID。
