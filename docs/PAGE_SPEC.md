# 页面与交互规格（PAGE_SPEC）

本文件定义信息架构、路由、逐页模块与交互状态。全局视觉规范见 [DESIGN](./DESIGN.md)；数据模型与实现见 [IMPLEMENTATION](./IMPLEMENTATION.md)；产品目标与边界见 [初版PRD](../初版PRD.md)。

原型与小程序保持同一套结构、文案与视觉比例。

## 1. 信息架构

```text
时间线页 #/timeline（落地页，默认今天）
├── 切换视图 → 列表页 #/list
│                └── 切换视图 → 网格页 #/grid
│                                  └── 切换视图 → 时间线页
├── 搜索入口 → 搜索页 #/search
│                └── 结果卡片 → 详情页 #/detail/<id>
└── 番剧卡片   → 详情页 #/detail/<id>
                  └── 返回 → 来源页（时间线 / 列表 / 网格 / 搜索）
```

页面总数：**5 个**（时间线、列表、网格、详情、搜索）。

## 2. 路由表

| 页面 | hash 路由 | 进入方式 | 返回目标 |
| --- | --- | --- | --- |
| 时间线 | `#/timeline` | 默认、视图切换、返回 | — |
| 列表 | `#/list` | 时间线左上角切换 | 时间线 |
| 网格 | `#/grid` | 列表左上角切换 | 列表 |
| 详情 | `#/detail/<id>` | 任意番剧卡片、搜索结果 | 记录在 `state.returnTo` 的来源页 |
| 搜索 | `#/search` | 时间线 / 列表 / 网格右上角 | 记录在 `state.returnTo` 的来源页 |

- 未知路由回退到 `#/timeline`；未知详情 id 回退到默认番剧 `tenchi`。
- 返回详情时保留搜索关键词；从时间线切到其他视图时重置筛选为「全部」。

## 3. 页面规格

### 3.1 时间线页（`#/timeline`）

| 区域 | 内容与规则 |
| --- | --- |
| 顶栏 | 左：视图切换（时间线 → 列表）；中：标题「番剧时间轴」（随当前页切换，不加粗）；右侧留空以保持标题居中，搜索入口统一放在底部 Tab Bar。标题行高度按状态栏高度与 `wx.getMenuButtonBoundingClientRect()` 反推，使标题与左侧按钮的中线和右上角原生胶囊重合（取不到时回退 88rpx） |
| 周日期条 | 7 个等宽文字标签「周一…周日」，按北京时间动态生成当前自然周（周一至周日），默认选中今天；选中态为标签下方的滑动下划线，固定在顶栏下方，不随滚动移动；具体日期在下方日期栏显示；标签行下方留白 10px（20rpx），不紧贴日期栏 |
| 日期栏 | 当前日期 + 星期；跟随周日期条固定；筛选与搜索入口移至底部悬浮胶囊 Tab Bar |
| 时间线主体 | 左侧时间轴竖线 + 时间标签 + 海报 + 标题/日文名/标签/集数；按时间升序分组；时间节点吸顶在日期栏下方 |
| 空状态 | 两种文案：当日无番剧、筛选无结果（带「查看全部」） |

单条卡片交互：点击卡片 → 详情。整页左右横向滑动可在相邻日期间切换（左滑到下一天、右滑到上一天），滑动过程中下划线实时跟手并拉伸。

### 3.2 列表页（`#/list`）

- 顶栏与时间线一致，标题为「番剧列表」，左上角图标语义变为「切换到网格视图」；顶栏（标题 + 星期分段标签）整体固定，不随滚动移动。
- 与时间线共用同一套星期分段标签（文字 + 滑动下划线），替代原有的胶囊式日期块。
- 卡片：海报 + 标题 + 日文名 + 元信息胶囊（`时间 + 已播/待播`、`# 第N集`、国漫标识）。
- 底部留白，点击整卡进入详情。

### 3.3 网格页（`#/grid`）

- 三列海报网格，封面左下角叠加半透明时间标签「HH:MM 播放」；顶栏（标题 + 星期分段标签）整体固定，不随滚动移动。
- 标题两行截断；点击进入详情。
- 左上角图标语义为「切换到时间线视图」，标题为「番剧网格」。

### 3.4 详情页（`#/detail/<id>`）

| 区块 | 内容 |
| --- | --- |
| 头图 | 海报模糊背景 + 返回；海报、标题、集数、放送状态。头图背景连同状态栏区域一起绘制，顶部不出现无背景的白色横带 |
| 下一集卡 | 第 N 集 / 共 M 集、放送日期（北京时间）、距开播倒计时 |
| 简介 | 简介文本，默认最多 4 行 |
| 信息 | 来源徽章（漫画改编 / 轻小说改编 / 原创动画；漫画改编为浅紫、原创动画为浅粉）+ 集数、季度、放送状态、制作、类型、放送时段 |
| 工作室 | 制作公司胶囊 |
| 标签 | 默认展示 6 个，可「更多 / 收起」 |
| 回到顶部 | 右下角悬浮按钮 |

详情页底部页面级留白，避免最后一行贴安全区，并为右下角「回到顶部」按钮预留空间，避免遮挡标签「更多」按钮。

### 3.5 搜索页（`#/search`）

- 顶部：返回按钮 + 玻璃搜索框（含清空按钮）。页面不再放置大标题与说明文案，以搜索框作为第一视觉层；聚焦时搜索框显示一圈淡蓝色光晕。
- 空关键词：展示「最近搜索」与「按标签探索」两组。
  - 最近搜索：索引式玻璃面板，每行由时钟图标 + 关键词 + 右上箭头组成，行间用发丝线分隔；标题右侧可「清空」；无记录时以虚线卡片提示，并引导使用下方标签。
  - 按标签探索：从当前番剧数据中统计出现次数最多的 8 个标签（跳过来源与分类标签），标签右侧显示数量；点击标签即填入关键词并记录。
- 有结果：「搜索结果」+ 关键词回显 + 右侧大号数量；结果集中在同一块玻璃面板内，行间以发丝线分隔，包含海报、标题、日文名、星期时间、番剧/国漫与第 N 话。
- 匹配范围：标题、日文名、制作公司、季度、分类（番剧/国创/国漫）、tags、extraTags、genres。
- 无结果：空态回显关键词「没有找到「关键词」」，提示更换关键词或从标签入口重新选择。

### 3.6 底部悬浮胶囊 Tab Bar

时间线、列表、网格三页共用一条悬浮在页面底部的胶囊 Tab Bar，分左右两部分：

| 部分 | 内容 | 规则 |
| --- | --- | --- |
| 左侧筛选组 | 全部 / 番剧 / 国漫 | 每项为「图标 + 文案」纵向排列（层叠 / 放送 / 地球），三枚等分嵌在一个玻璃胶囊内；选中背景撑满对应 Tab，图标与文案转为强调色 `#0a84ff`；切换后保持滚动位置，视图切换时筛选不变 |
| 右侧搜索胶囊 | 搜索图标 | 独立圆形玻璃胶囊，与主胶囊等高，点击进入搜索页 |

- 布局：屏幕左右固定边距 20px（小程序 38.46rpx），主胶囊 `flex: 1` 占满剩余宽度，搜索胶囊固定 56px × 56px（小程序 107.69rpx），两者间距 8px（15.38rpx）；整组约占屏宽 90%，宽度由容器分配而非内容撑开。
- 外形：主胶囊高 56px（小程序 107.69rpx），圆角取高度一半 28px（53.85rpx），呈完整胶囊形态；内层 Tab 圆角 23px（44.23rpx），主胶囊内边距 5px（9.62rpx）。
- 距底部 20px（小程序 38.46rpx），与左右固定边距一致；小程序不再叠加 `env(safe-area-inset-bottom)`，避免安全区把底部间距撑成左右边距的两倍以上（底部内容留白仍保留安全区）。
- 容器本体不接收事件，仅胶囊本身可点击，避免遮挡底部卡片的滚动与点击。
- 三页底部留白相应加大（原型 82px、小程序 157.69rpx，含安全区），避免最后一行内容被 Tab Bar 覆盖。
- 切换动效：选中胶囊由独立指示层承载，前沿与后沿分别用不同刚度的弹簧追赶目标，前沿先到、后沿稍慢并轻微回弹，中途胶囊被拉长且高度略压扁，约 420ms 停稳；新选中的图标先缩小再弹回，文字颜色在约 280ms 内渐变到强调色；页面内容沿点击方向轻推 14px 并淡入。最终选中态与静态样式完全一致，开启「减少动态效果」时直接跳到终态。

## 4. 交互与状态

| 状态 | 触发 | 表现 |
| --- | --- | --- |
| 视图循环 | 左上角按钮 | 时间线 → 列表 → 网格 → 时间线 |
| 日期切换 | 星期分段标签 | 点击标签：下划线与内容同步滑向目标；下划线下方的文字随进度由灰变深并加粗 |
| 横向滑动切换日期 | 在时间线 / 列表 / 网格页横向滑动 | 下划线实时跟手：前缘领先、后缘滞后，中途像毛毛虫一样拉长，落点收回；松手按距离 + 速度吸附到最近的一天并轻微回弹；单次滑动最多只切换相邻一天（速度再快也不跨格），首尾日期不循环；纵向为主的滑动不触发 |
| 时间线滚动 | 纵向滚动时间线 / 列表 / 网格 | 顶栏区块（标题 + 星期分段标签，时间线另含日期栏）在三个视图中均固定不滚动；当前分组的时间节点始终吸顶在日期栏下方；滚动到下一时间点时，新节点从下方将旧节点顶出 |
| 筛选 | 底部 Tab Bar 的全部 / 番剧 / 国漫 | 保持滚动位置筛选；选中胶囊以液态弹簧动效流向新 Tab（前沿先到、后沿回弹、中途拉伸压扁，约 420ms），图标先缩后弹、文字渐变强调色，内容沿点击方向轻推淡入；无结果时引导去查看全部；在时间线 / 列表 / 网格间切换视图时筛选保持不变 |
| 打开搜索 | 底部 Tab Bar 的搜索胶囊 | 进入搜索页；返回时回到来源视图 |
| 键盘 | Enter / Space | 聚焦卡片时打开详情 |
| 回到顶部 | 详情右下角 | `scrollTop = 0` |
| 刷新 | 浏览器刷新 | 内存态（筛选、关键词、搜索历史）重置为初始值 |
